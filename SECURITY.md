# Security

Report a vulnerability through GitHub private vulnerability reporting:

<https://github.com/Innovgame/slicer-converter/security/advisories/new>

Do not post an unfixed vulnerability, exploit steps, or private sample files in a public issue, pull request, or discussion. Include the affected version or commit, the conditions you used, and what you have already verified.

There is no separate security email. Maintainers will describe the impact when a fix is released.
